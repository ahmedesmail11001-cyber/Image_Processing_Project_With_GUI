HOW TO SET-UP


GUI Program

Requirements:

IDE: Qt Creator
Build System: CMake (Minimum Version --> 3.16)
Compiler: MinWG 13.1.0 64-bit (GCC)
Qt Version: Qt 6.11.2


Set-up Instructions:

Download the Qt 6 installer: https://www.qt.io/development/download-qt-installer-oss
During set-up:
Customize --> Qt for Development --> Qt --> Check Qt 6.11.2 or Higher version (6.xx.x)
Customize --> Qt for Development --> Qt --> Build Tools --> Check MinWG 13.1.0 64-bit & Check CMake 3.30.5 & Check Ninja 1.12.1
Ensure Qt Creator is installed

3. Ensure the extraction ISN'T on OneDrive

4. From Qt Creator, Open Project --> Select Image_Processing_with_GUI --> Select the CMakeLists File

5. Select the Kit (e.g. Desktop Qt 6.11.2 MinGW 64-bit) & Check the boxes under it

6. Run the Program
